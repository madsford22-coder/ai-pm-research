# October 2026 Research Summary

The agent economy just hit an inflection point where cost and governance matter more than raw capability. This month, every major company shipping agents—LangChain, Notion, Microsoft, Anthropic—stopped chasing model quality and started building the unsexy infrastructure layer: routing logic to cut costs 64%, shared skill libraries so teams don't rebuild the same capability twice, and memory systems that let agents and humans edit the same workspace without stepping on each other. The message is clear: agents that actually work at scale are built on plumbing, not just prompts.

The other signal this month is trust fracturing. Instinct went from "one agent, one person" to group chats where the agent acts for multiple people with conflicting interests. OpenAI started running ads inside ChatGPT's conversational responses. Ben Tossell publicly called his Dot experience bad while Karri Saarinen quietly switched from Meta's Muse to OpenAI's Dot for personal use, then kept his work AI separate inside Linear. What's emerging isn't one "AI operating system" everybody converges on—it's fragmented, context-dependent trust where users run multiple agents for different jobs and actually switch based on experience, not brand loyalty.

## What Matters

- **Cost routing is now table stakes, not optimization.** LangChain cut Open SWE's median coding-task cost by 64% with a model router that picks the right model per step, no quality drop. Same week, Anthropic shipped Haiku 5.5 at 75% cheaper than Haiku 4.5, explicitly for subagents. Microsoft pushed inference to local models "when it makes sense." This isn't three companies being clever—it's the baseline expectation shifting. If you're running a single frontier model for every task, you're overpaying by 2-5x. The router (which model for which task) is now where differentiation lives, not the model itself.

- **Shared infrastructure beats isolated AI features.** Notion shipped a skills library that treats agent capabilities like any other shared doc—edit once, govern once, reuse everywhere. The same team also published how CRDTs handle concurrent edits between humans and agents without data loss. This solves the problem every team eventually hits: one person builds a useful automation, a second person needs it, and there's no place to store or govern it except Slack. Notion is betting that governance and knowledge-sharing, not raw capability, is the bottleneck for agents inside companies. Figma's AI agent exiting beta tied to latency and search improvements (not new features), which suggests infrastructure boring-ness is what makes AI features actually ship.

- **Personal agents are fragmenting by context and trust, not consolidating around one.** Karri Saarinen uses OpenAI's Dot for personal projects but keeps work AI inside Linear for context. Noah Shinn's Instinct hit 20% user adoption on the unsexy use case (flights) nobody expected to be the driver, so they rebuilt it. Instinct then expanded to group chats, which immediately breaks the single-owner trust model. Ben Tossell's public "Dot experience has been 💩" plus Tibo Sottiaux's interview claiming Dots is OpenAI's biggest bet show internal conviction and lived experience pointing in opposite directions. The pattern isn't "which agent wins," it's "users pick agents by job and switch based on whether it actually works," and nobody wins by being everything to everyone.
