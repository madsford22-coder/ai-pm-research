# October 2026 Research Summary

The agent question shifted this month from "can it do the task" to "who's accountable when it does." Figma's agent went GA with latency fixes instead of new features, OpenAI's Dots got a public trust gap when Ben Tossell said his experience was terrible right after the company's leadership called it their biggest bet, and Instinct expanded into group chats where suddenly the agent has to decide whose calendar, credentials, and preferences win when five people disagree. These aren't product-feature stories—they're trust and governance stories wearing product-release clothing.

The infrastructure layer for agents is now where the real build is happening. Notion turned its document editing model into a substrate for shared agent skills and persistent memory across multiple agents, LangChain's model router cut coding costs 64% by routing simpler tasks to cheaper models, and Linear's own bug-autofix loop chains Datadog and Sentry into a repair cycle that's fixed 300+ bugs in a month. The pattern is clear: teams don't care about raw agent capability anymore, they care about whether they can govern it, remember what it decided, and afford it at scale.

## What Matters

- **Beta-to-GA isn't about adding features, it's about fixing infrastructure.** Figma's agent graduation focused on latency and file search, not new capabilities. This signals that adoption blockers for AI features aren't always capability gaps—they're the unsexy infrastructure work (speed, discoverability, multiplayer conflict resolution) that determines whether a beta feature becomes something a team actually relies on daily. If you've shipped an AI feature that's stalled in beta, audit whether your blocker is capability or infrastructure before you add more features.

- **Personal agents are splintering into context-dependent usage, not consolidating into one "operating system for life."** Karri Saarinen (Linear's CEO) switched from Muse to Dot for personal projects but kept Linear's own AI for work because of contextual depth. This fragmentation suggests users will run multiple agents optimized for specific contexts rather than betting everything on one platform, which changes how Meta, OpenAI, and Instinct should think about lock-in. The winner isn't the agent that does everything; it's the agent that's deeply integrated into the specific workflow you actually need.

- **Model routing and evals are where product differentiation lives now, not model capacity.** LangChain cut 64% off coding task costs by routing simpler work to cheaper models, Teresa Torres' Vistaly case study shows AI-generated discovery insights need explicit repair loops to catch hallucinations, and Notion's skills library lets teams govern shared agent memory instead of rebuilding context every time. The infrastructure and judgment layers—routing decisions, evaluation gates, shared governance—are the real product moats now.
