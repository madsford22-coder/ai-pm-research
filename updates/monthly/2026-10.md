# October 2026 Research Summary

The agent economy just hit its first real reckoning: cost, trust, and governance are eating the lunch that raw capability used to own. Three separate companies published 64% cost reductions this month just by routing tasks to cheaper models, Microsoft pushed inference to the edge to cut token burn, and Anthropic shipped a model explicitly built for subagents instead of chat. Meanwhile, every conversation about personal agents—Muse, Dot, Instinct—has quietly shifted from "what can it do" to "whose credentials is it using when things go wrong" and "will I actually trust it to spend real money or handle my calendar alongside five other people's calendars."

The second story threading through October is that shared infrastructure beats individual tools at scale. Notion published three posts on agent skills libraries, shared memory, and CRDT conflict resolution; Figma graduated its agent from beta by making it faster and more findable, not flashier; and Postman's case study of serving 40 million developers revealed that tool sprawl and context management, not model quality, are the actual bottlenecks at scale. The companies shipping real adoption are the ones solving "how does a team govern and remember what the agent knows" rather than "how does a single agent impress a user in a demo."

## What Matters

- **Model routing isn't optimization anymore, it's baseline architecture.** LangChain cut coding task costs 64% by routing subtasks to cheaper models based on complexity; Anthropic released Haiku 5.5 at 75% cheaper than Haiku 4.5, explicitly positioned for subagent work; Microsoft pushed local models to edge devices to cut cloud token burn. If you're running agent workflows on a single frontier model for every call, you're leaving 2–5x on the table and there's now a playbook to fix it. The routing decision (which model for which task type) is becoming the real product work, not the model capability itself.

- **Agent infrastructure for teams solves the problem individual AI tools can't.** Notion's skills library lets teams manage agent capabilities like any other shared doc, governed and versioned the same way, reusable across multiple agents. Their CRDT deep-dive shows they've thought through what happens when a human and an agent write to the same page at the same time. Figma's agent exited beta specifically because latency and file search (not new features) were the adoption blockers. The signal: team adoption stalls when agents feel like one-off integrations; it accelerates when they're plumbed into how the team already works.

- **Personal agent trust is fragmenting by context, not consolidating around one "OS."** Stripe's Monetize 2026 summit revealed everyone's still wrestling with AI pricing economics (token billing is broken-but-unkillable); Karri Saarinen publicly switched from Meta's Muse to OpenAI's Dot for personal use while keeping Linear's own AI for work; Instinct shipped group chat support and autonomous customer service calls, pushing into higher-autonomy territory. The pattern: users aren't picking one agent and staying loyal. They're evaluating by task fit, trust level, and integration depth. Instinct's 20% of users relying on flight booking tells you more about agent adoption than any benchmark—people use agents for unglamorous, high-frequency logistics, not novel philosophical tasks.
