# October 2026 Research Summary

The agent cost war just ended before most people realized it was happening. Three separate companies published case studies this month showing 60-76% cost reductions on real tasks—LangChain's model router cutting coding costs 64%, Anthropic shipping a subagent-specific model 75% cheaper than its predecessor, Microsoft pushing inference to local devices—and not one of them was framed as a competitive advantage. They were all framed as table stakes. The industry has collectively moved past "which model is smartest" to "which model for which task, and how do you route between them without the user noticing."

But the harder conversation is happening in parallel, mostly quietly. Instinct is rebuilding its core around flights (the most boring use case possible) because 20% of users want it there, while simultaneously pushing group-chat autonomy and agent-initiated spending. Notion is building infrastructure for teams to share agent skills and persistent memory. Figma graduated its agent from beta by fixing latency and search, not by adding flashy new capabilities. These aren't product announcements, they're infrastructure decisions. The question isn't whether agents work anymore—it's whether teams can govern them, remember what they decided, and afford to run them at scale.

## What Matters

- **Usage data beats founding narrative.** Instinct launched on novel, high-autonomy task completion, but 20% of users organic­ally reach for the agent to book flights—the most unglamorous travel tech problem that exists. Noah Shinn responded by rebuilding the flight experience from scratch rather than chasing the sexier roadmap item. This is the pattern every agent product hits eventually: the data tells you where users actually want AI to work, and it's almost never the ambitious vision you pitched. For PMs, this means your Q4 roadmap should start with a usage audit, not a capability wish list.

- **Routing cheaper models for routine tasks is now baseline.** LangChain's model router (64% cost cut, no quality drop), Anthropic's Haiku 5.5 (75% cheaper for subagent work), and Microsoft's local-model strategy all converge on the same architecture: expensive frontier models for hard reasoning, cheap models for easy tasks. If your product is still sending every request to your most expensive model because it's simpler than building a router, you're now leaving 2-5x cost reduction on the table. This went from "clever optimization" to "obviously the right call" in about four weeks.

- **Trust infrastructure matters more than model capability.** Notion's CRDT system for concurrent editing (agents and humans writing to the same doc), skills libraries for reusable agent behavior, and "Lore" for persistent shared memory aren't flashy features—they're the unglamorous plumbing that lets a team actually use agents without constant context loss and permission nightmares. Figma's agent hit GA by improving latency and file search, not by adding new capabilities. Ben Tossell publicly criticized OpenAI's Dots the same week the company's own Head of ChatGPT called it the biggest bet, proving that internal confidence and external usability are different data points. Teams are choosing agents based on governance and integration depth now, not raw capability.
