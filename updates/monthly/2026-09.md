# September 2026 Research Summary

September revealed the gap between what AI *can* do and what teams will actually *let* it do. OpenAI published internal data showing their research team runs 3x faster with coding agents. Perplexity shipped hybrid compute so sensitive work never leaves your Mac. Anthropic's Fable 5.1 got fast enough that it matters for production systems. But underneath all of this — the faster models, the new capabilities, the architectural patterns — the real story is about trust, governance, and control. Teams aren't adopting AI because it exists. They're adopting it when they can see exactly what it's doing and can stop it if they need to.

The month also made clear that "which model should we use?" is the wrong question now. GitHub published Project HydraFusion routing tasks across multiple models. Lenny and Dan tested Astra against Fable and found them winning on different dimensions — one better at code, one better at judgment calls. The real competitive advantage isn't model capability anymore. It's orchestration, memory management, and knowing where to route work to get reliable output.

## What Matters

- **Agent memory is moving from opaque vectors to human-readable stores.** Notion shipped Lore, which turns agent memories into regular Notion pages that people can actually read, edit, and correct. AWS published a production-grade memory lifecycle management pattern for long-running agents, using Step Functions to automatically prune stale context and prevent compliance violations. This matters because most teams default to vector databases that nobody except engineers can inspect — Notion proved there's a better way.

- **Hybrid compute is the architecture that unlocks enterprise adoption of agentic tools.** Perplexity shipped local model orchestration on Mac so sensitive files never route to the cloud. Cursor answered the enterprise security objection directly with self-hosted machines for Cloud Agents. OpenAI went vertical with EHR integration for healthcare teams. The pattern: instead of asking users to trust cloud security, give them the infrastructure to keep sensitive work local while still getting cloud capabilities where it doesn't matter.

- **AI quality measurement just became table stakes for product teams.** Teresa Torres published a hands-on evals guide designed specifically for PMs, with a downloadable test harness that removes the activation energy barrier. Jamf published their real-time per-user cost governance architecture using IAM policies and Lambda loops. GitHub documented their cost vs. quality tradeoff openly. Three separate signals saying the same thing: if you're shipping an AI feature without evals or cost visibility, you're flying blind.
