# August 2026 Research Summary

August opened with a fundamental tension surfacing in AI product design: as execution gets faster and cheaper, what does a PM actually do? Perplexity turned Computer from a solo tool into a multiplayer agentic OS with persistent memory. Tom Verrilli, CPO of Whatnot, went public saying he regrets product management exists as a distinct function. Both moves point at the same question — the coordination layer that PM traditionally provided is becoming obsolete faster than expected.

Running parallel to this is a shift in how enterprises treat AI costs. Atlassian announced per-employee token budgets ($500-$2,000/month). Vercel shipped cost observability and spend alerts at the infrastructure layer. These aren't coordination tools — they're governance tools. The message is clear: the "AI is free to experiment with" phase is closing.

## What Matters

- **Team agentic workspaces are becoming real infrastructure, not just features.** Perplexity's Projects launch makes Computer a multiplayer operating system with shared persistent memory across users and sessions. This is different from ChatGPT Projects or Notion agents because Perplexity Computer already does real computer-use tasks (clicking, typing, navigating) — the shared state makes it genuinely collaborative infrastructure. For PMs, this changes the procurement conversation: it's no longer "per-seat productivity tool," it's "team operating environment."

- **PM roles are being pressure-tested by two forces simultaneously.** Tom Verrilli's argument is sharp: PM proliferation created a coordination layer that slows decision-making, and fewer senior PMs doing real IC work outperform ratio-driven org design. This maps directly onto what's happening with AI tooling — if engineering execution gets faster and cheaper, coordination-heavy PM functions become redundant. The valuable part was always judgment and taste, not meeting-running and backlog-management.

- **AI cost governance is moving from invisible infrastructure to legible, measurable resource allocation.** Atlassian's per-employee token budgets and Vercel's spend controls are arriving simultaneously because the "free experimentation" phase is closing. For PMs building AI features for enterprise customers, this means procurement conversations will now include token consumption data and cost-per-outcome framing within two quarters. Stateless MCP improvements (Simon Willison's signal that the protocol is actually deployable now) suggest the infrastructure for this governance is standardizing quickly.
